# Netflix Data Analysis Using Python

A data analysis project developed as part of the Auspify Technologies Data Analysis Using Python Internship.

## Project Overview
This project explores Netflix movies and TV shows using Python, Pandas, NumPy, and Plotly.

## Tasks Completed
1. Netflix Data Cleaning & Preparation
2. Content Type Analysis
3. Country-Wise Content Analysis
4. Release Year Trend Analysis
5. Content Rating & Genre Analysis
6. Netflix Business Insights Report

## Technologies Used
- Python
- Pandas and NumPy
- Plotly
- Jupyter Notebook

## Dataset Summary
- Total titles: 8,790
- Movies: 6,126
- TV Shows: 2,664
- Content rating categories: 14
- Release year range: 1925–2021

## Key Findings
- Movies account for 69.69% of the dataset.
- The United States has the highest country-wise title count.
- TV-MA is the most common content rating.
- International Movies is the most frequent genre category.
- 2018 is the peak release year in the dataset.

## Visualizations
The project includes 35 interactive HTML charts across the task output folders.

## Project Structure
- `data/raw/` — Original dataset
- `data/processed/` — Cleaned dataset
- `Task_01_Data_Cleaning/` — Data preparation
- `Task_02_Content_Type_Analysis/` — Content type analysis
- `Task_03_Country_Wise_Analysis/` — Country analysis
- `Task_04_Release_Year_Trends/` — Historical trends
- `Task_05_Rating_Genre_Analysis/` — Rating and genre analysis
- `Task_06_Business_Insights/` — Business insights and charts
- `reports/` — Final reports

## How to Run
1. Install the required packages:
   `pip install -r requirements.txt`
2. Open Jupyter Notebook.
3. Open the notebooks inside each task folder.
4. Run the cells in order.
